窗口管理

实时窗口句柄拾取、层级调整、置顶控制、透明度调节、后台截图等全面的窗口操控能力。
  • 实时窗口句柄拾取，鼠标拖拽选择屏幕区域自动识别并高亮目标窗口
  • 窗口层级调整，快捷键快速调整 Z 轴层级（置顶/置底/普通）
  • 一键控制窗口置顶、禁用/启用交互能力
  • 窗口整体透明度、指定透明颜色、鼠标穿透设置
  • 后台截图功能，即使窗口被遮挡也可截取，支持右键启用网页实时预览
  • 通过句柄快速定位并闪烁高亮目标窗口
  • 查看和修改窗口位置、大小、标题、类名等属性
  • 最小化、最大化、销毁等窗口状态控制
  • 截图权限管理，查询、启用或禁止截图保护

布局管理

可视化区域拖拽、布局持久化、撤销/重做、布局分享，灵活定制你的工作界面。
  • 主界面分为句柄区域、清理区域、函数区域、操作区域等多个面板
  • 支持拖拽移动和调整各区域大小
  • 所有布局通过 XML 文件（布局.xml）自动保存和恢复
  • 支持 Ctrl+Z 撤销和 Ctrl+Y 重做布局操作
  • 通过系统菜单导出当前窗口布局文件，实现布局分享
  • 双击任意区域可进入详细属性编辑页面

API Hook 管理

指定 DLL 路径和函数名拦截 Windows API 调用，支持安装、卸载、暂停、恢复等完整生命周期管理。
  • 指定 DLL 路径和函数名，安装 Hook 拦截 Windows API 调用
  • 对已安装的 Hook 进行卸载、暂停、恢复等生命周期管理
  • 检查指定函数是否已被 Hook
  • 获取被拦截函数的内存地址
  • 一键清除所有 Hook，程序退出时自动执行

快捷键系统

内置高效快捷键方案，快速调整窗口层级、撤销/重做布局操作，大幅提升操作效率。
  • Ctrl + Z：布局撤销
  • Ctrl + Y：布局重做
  • Ctrl + T：鼠标所在窗口层级 置顶
  • Ctrl + D：鼠标所在窗口层级 重置
  • Ctrl + S：鼠标所在窗口层级 置底
  • F5：停止后台截图实时预览

鼠标追踪与窗口识别

实时鼠标坐标显示、控件标题识别、多层级窗口选取，精准定位每一个窗口元素。
  • 开启后实时显示鼠标在屏幕上的精确坐标
  • 自动识别鼠标悬停处的控件标题
  • Ctrl / Shift / Alt + 鼠标悬停，分别选取祖窗口 / 父窗口 / 子窗口
  • Alt + A/S 在同一父窗口的多个子窗口间循环切换

启动与运行

双模式启动、托盘运行、在线版本检测、拖放文件支持，灵活适配不同使用场景。
  • 支持普通模式（完整导航界面）和性能模式（轻量启动）
  • 可设置跳过启动页直接进入工具箱
